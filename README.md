> High-performance, conversion-engineered developer portfolio and 3 production concept pieces ready for deployment on Vercel, Cloudflare Pages, or any static edge CDN.

## ⚡ Architecture & Tech Stack

- **Zero Heavy Frameworks:** Pure semantic HTML5, modern modular CSS (CSS Grid, Flexbox, CSS Variables, `clamp()` fluid typography), and vanilla JavaScript.
- **Sub-Second Performance:** Engineered for 99+ Google Lighthouse scores, 0 Cumulative Layout Shift (CLS), and sub-600ms Largest Contentful Paint (LCP).
- **Target Audience:** US & European tech startups, digital agencies, and luxury consumer brands.
- **Conversion Rate Optimization (CRO):** High-intent value propositions, dynamic pricing toggles, interactive variant selectors, instant table reservations, and frictionless lead capture forms.

## 🚀 Instant Deployment to Vercel

### Option 1: Vercel CLI (Recommended)
From inside the `portfolio-ignacio` folder:
```bash
npm i -g vercel
vercel
```

### Option 2: GitHub + Vercel Dashboard
1. Initialize git and commit:
   ```bash
   cd portfolio-ignacio
   git init
   git add .
   git commit -m "feat: complete portfolio & concept pieces"
   ```
2. Push to your GitHub repository (`portfolio-ignacio`).
3. Connect your repository on [vercel.com](https://vercel.com) — no build command or output directory configuration needed (pure static zero-config).
